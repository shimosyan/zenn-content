Ubiquiti UniFi にて管理者ページの SSO が設定できるようになりました。

ただ、いつもの SSO の設定とはフローが異なるクセがつよいものだったので、備忘録としてメモを残したいと思います。

## 動作要件

- UniFi Network 10.5
- Identity Sync Service 1.8.1

## 前提知識

- SSO の入口はユーザー向けと管理者向けの2通り存在する
- 認証プロトコルは OIDC
  - つまるところ SP-Initiated のみ

## Entra ID での設定のすすめ

### ユーザー向け SSO の設定

まずはユーザー向けの設定が必要です。

- Site Manager で Fabric を作る
- Site Manager にいずれかの UniFi サイトを登録する
- Site Manager の設定から Identity ページを開いて、Consolidated People Management を有効化
- （おすすめ）Vanity Domain を設定する
- Entra ID を選択する。設定モードでは Manual ではなく UniFi 手動の自動設定モードがおすすめ
- まずはユーザー向けの SSO 設定を開始する。UniFi が Entra ID の Graph API を介して、Entra ID に自動で設定を作ってくれるので API の認可を実施。
- 設定が完了すると、同期に関する設定ができるようになる。ここでは Entra ID のどのグループを同期するか選択できる。ここで利用させたいユーザーが含まれているグループを選択して保存

ユーザーのインポートが走り、Site Manager のユーザー一覧に Entra ID のユーザーが取り込まれます。
この際、ユーザーに招待メールが飛びます。

ユーザー向け機能はデスクトップまたはスマホアプリの「UniFi Endpoint」経由でログインします。
このとき、先に設定した Vanity Domain を入力することでログインできます。

### 管理者向けSSO設定

- Site Manager の設定から Identity ページを開いて、Enforce IdP Authentication を有効化する
- UniFi が Entra ID の設定を自動で作成するために API の認可を求められるのでそれに同意
  - ここで Entra ID に作成されるアプリケーションはユーザー向けとは別のものになる
- 無事設定が完了したら、通常の ID＆PW でログインできる Fallback Admins を指定して保存
- Site Manager のユーザー一覧を開いて、管理者ログインさせたいユーザーに管理者権限を割り当てる

Vanity Domain を開いたあとに表示されるいつものログインページで管理者権限が付与されたアカウントの ID を入力すると SSO ログインができるようになります。

## ハマったところ

### ユーザーの割り当てについては普段の SAML、OIDC、SCIM とは異なる

通常とは異なる以下の通りの挙動をします。

- 通常：IdP でユーザーを割り当て & SCIM でユーザー同期
- UniFi：Identity ページで同期する Entra ID グループを指定。このグループのメンバーが自動で UniFi にインポートされる。
  - また、管理者向けの Entra ID アプリケーションにおいては注意が必要。 UniFi が API 経由で割り当てメンバーを上書きするため、Entra ID を起点とした制御ができない

### マニュアル設定はいろいろ問題あり

「マニュアル」で設定を進めると、 SAML と SCIM を前提としたような設定フローとなります。

このモードで設定すると、いつも通り Entra ID でユーザー制御をできるような雰囲気ですが、上記のように Entra ID のアプリケーションの割り当てメンバーを UniFi が上書きしてくるため思うような設定ができません。（SCIM の意味とは）

### その他

フローが特殊かつ UniFi から API で操作してくるため、Entra ID 側のアプリケーションは「ユーザーへの表示」を除いて変更しないことをおすすめする。
